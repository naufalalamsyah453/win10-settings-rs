# Roadmap

## Phase 0: bootstrap

- Git, workspace, CI, repository, performance baseline.

## Phase 1: shell and design system

- Material 3 tokens, components, navigation, search, custom title bar.
- Build `light` and `gpu` variants; measure both; choose the default.

## Phase 2: catalog and read layer

- Full page catalog with metadata and deep links.
- Windows read implementations with lazy loading and error states.

## Phase 3: personalization and system writes

- Wallpaper, accent, theme, transparency, brightness, volume, resolution,
  power, battery saver, backup and restore.

## Phase 4: remaining writes

- Apps, privacy, time, ease of access, gaming, accounts, update status,
  elevation helper.

## Phase 5: polish and performance

- Motion, keyboard navigation, accessibility, localization, performance tuning,
  and final comparison against native Settings.

## Phase 6: release

- Portable ZIP for both renderer variants, installer, release workflow,
  screenshots, and documentation.
